# 🐺 Wolverine: Last Claw

### An Independent Wolverine-Inspired 3D Action Game

*A new breed of browser-based gaming.*

Wolverine: Last Claw is an independent 3D action game built to deliver an immersive Wolverine-inspired experience with cinematic presentation, intense combat, exploration, and a dedicated desktop-style launch experience.

Unlike a traditional browser game, Last Claw offers two different ways to play: directly through Microsoft Edge or in its own standalone application window.

---

## 🎮 How to Play

There are two ways to launch the game on Windows.

### Option 1 — Browser Mode

**File:** `play.bat`

Launches Wolverine: Last Claw in a regular Microsoft Edge browser window.

1. Download or clone this repository.
2. Open the game folder.
3. Double-click `play.bat`.
4. The game launches in Edge.

### Option 2 — Standalone App Mode

**File:** `play-edge.bat`

Launches Wolverine: Last Claw in its own dedicated application window, without the normal browser interface.

1. Download or clone this repository.
2. Open the game folder.
3. Double-click `play-edge.bat`.
4. Allow the required Edge application/runtime components to download if prompted.
5. Once setup is complete, the game launches in its own app window.

**Note:** An internet connection is required for the initial download of the standalone app components. Subsequent launches may not require another download.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Wolverine-Last-Claw.git
```

Navigate into the folder:

```bash
cd Wolverine-Last-Claw
```

Then choose your preferred launcher:

```text
play.bat       → Browser Mode
play-edge.bat  → Standalone App Mode
```

No manual browser navigation should be necessary when using the supplied launchers.
